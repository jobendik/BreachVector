# Asset Replacement Guide

The current build uses generated Phaser textures and procedural audio. This file lists real assets that can replace placeholders later.

## Art Direction

Dark tactical sci-fi with readable neon accents. Keep silhouettes crisp and avoid detail that hides gameplay information. Suggested accent palette: cyan for technology, green for objectives/player, amber for warnings, red for alerts, violet for rare/power weapons.

## Player

- `operator_idle.png`
- `operator_run.png`
- `operator_dash.png`
- `operator_aim.png`
- `operator_hit.png`
- `operator_death.png`

Recommended: 64x64 or 96x96 sprites, 8 directional or top-down rotational weapon mount.

## Enemies

- `enemy_assault_idle/run/fire/death`
- `enemy_sniper_idle/run/fire/death`
- `enemy_flanker_idle/run/fire/death`
- `enemy_heavy_idle/run/fire/death`
- `enemy_captain_idle/run/fire/death`

Each role should have a distinct silhouette visible at minimap scale and in fog.

## Projectiles And Effects

- Bullet tracer sprites
- Pellet sparks
- Rail beam segment
- Grenade sprite
- Explosion atlas
- Smoke puffs
- Debris particles
- Hit sparks
- Damage number font or bitmap font

## Tileset And Environment

- Floor tile set with grid variants
- Wall panels
- Door frames and animated security doors
- Terminal console sprites
- Crates and explosive barrels
- Decals: scorch marks, bullet impacts, blood/synthetic fluid
- Extraction zone pad

Recommended: build with Tiled and export JSON maps when replacing rectangle geometry.

## UI Assets

- HUD panel frames
- Health, armor, dash, ammo, grenade, objective, alert, and debug icons
- Minimap frame and blips
- Button states
- Tactical monospace bitmap font

## Audio

- Silenced pistol shot
- Pulse rifle shot
- Scattergun blast
- Rail piercer charge and shot
- Enemy weapon variants
- Reload sounds
- Dash sound
- Grenade throw and explosion
- Barrel explosion
- Hit flesh/armor/prop sounds

- Door unlock/open

- Sector clear sting

## Music

- Low-intensity infiltration loop
- Searching tension layer
- Detected combat layer
- Victory and game-over stingers

## Naming Conventions

Use lowercase kebab-case:

- `operator-run-01.png`
- `enemy-heavy-fire.png`
- `weapon-rail-piercer.png`
- `fx-explosion-atlas.png`
- `ui-health-icon.png`
- `sfx-pulse-rifle-shot.wav`

## Atlas Recommendations

- Pack character sprites by faction or role.
- Pack UI separately from world sprites.
- Keep particle textures in a small dedicated atlas.
- Use consistent origin points for top-down actors.
- Include JSON atlas metadata generated by TexturePacker, Aseprite, or a similar tool.
