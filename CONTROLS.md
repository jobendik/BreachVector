| Action | Input |
| --- | --- |
| Move | `W`, `A`, `S`, `D` |
| Aim | Mouse |
| Fire | Left mouse |
| Throw grenade | Right mouse |
| Reload | `R` |
| Dash | `Space` |
| Slow walk | `Shift` |
| Interact / hack / open | `E` |
| Melee / takedown | `F` |
| Switch weapon | `1`, `2`, `3`, `4` |
| Debug overlay | `Tab` or `F1` |
| Pause | `Esc` |

## Gameplay Tips

- Slow walking reduces the noise radius of player actions and helps preserve stealth.
- The Silenced Pistol is best for quiet picks; the Pulse Rifle is the reliable default.
- The Scattergun controls close-range rushes, while the Rail Piercer deletes priority threats but is loud and ammo-limited.
- Barrels can start chain reactions. Use them to clear patrol clusters or heavy units.
- Terminals unlock matching security doors. The command unit must be neutralized before extraction.
- If detected, emergency lighting improves readability but enemies coordinate faster.

## Stealth And Combat

Enemies use field-of-view and line-of-sight checks against walls, closed doors, and line-of-sight blocking cover. Noise can pull enemies into suspicious or search states even if they never saw the player. Once combat starts, the alert state shifts into detected mode and enemies attack, flank, seek cover, or reload based on role and situation.
